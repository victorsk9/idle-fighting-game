# Idle Fighting Game

Um jogo de luta idle desenvolvido em Go.

O projeto será construído gradualmente como um laboratório prático
para estudar desenvolvimento backend e desenvolvimento web.

## Objetivo

Criar um jogo onde o jogador pode evoluir seu personagem,
enfrentar inimigos e progredir mesmo quando estiver offline.

## Tecnologias

- Go
- HTTP
- HTML
- HTMX
- Templ
- PostgreSQL
- Docker

## Funcionalidades

- [ ] Criar personagem
- [ ] Sistema de atributos
- [ ] Sistema de combate
- [ ] Inimigos
- [ ] XP e níveis
- [ ] Equipamentos
- [ ] Sistema idle/offline
- [ ] Persistência com PostgreSQL
- [ ] Autenticação
- [ ] Ranking
- [ ] Deploy

## Objetivo de aprendizado

Usar o projeto para praticar conceitos de:

- Go
- HTTP e APIs
- Backend
- Banco de dados
- HTML e HTMX
- Testes
- Docker
- Arquitetura de aplicações web
